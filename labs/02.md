## Overview

This lab introduces you to ArcGIS Online and Collector for ArcGIS. You'll create web maps, configure data collection, and publish a web application.

---

## Task 1: Create a Web Mapping Application

Complete the tutorial: [Get Started with Map Viewer](https://learn.arcgis.com/en/projects/get-started-with-map-viewer/)

### What You'll Learn:
- Add layers to a map
- Import data from spreadsheets
- Change map symbols
- Configure pop-ups
- Share maps as web apps

### Submission Steps:

1. Login to your ArcGIS Online account
2. Navigate to **Content**

![Content1](../images/labs/02/task1handin1.png)

3. Find your web app and click **View Application**

![Content2](../images/labs/02/task1handin2.png)

4. Copy the application URL from your browser

![Content3](../images/labs/02/task1handin3.png)

5. Test your app in an incognito/private browser window to verify it works

**Important:** Name your web app: "My first Web App - [Your Name]"
Example: *My first Web App - Xiao Li*

---

## Task 2: Collector for ArcGIS

Complete the exercise: [Create and share a map for data collection](https://www.esri.com/arcgis-blog/products/collector/field-mobility/make-your-first-collector-map/)

**Note:** Select the appropriate operating system for your mobile device before starting.

![Task 2 warning](../images/labs/02/task2w.png)

### What You'll Do:
- Create a damage assessment map
- Add the **Damage Assessment** layer
- Configure the data collection form
- Customize application settings

![Task 2 content](../images/labs/02/task2content.png)

### Submission Steps:

1. Access your published web map on your mobile device
2. Login using **ArcGIS Enterprise** login option
3. Add a new feature to your map
4. Take a screenshot showing the feature you added

---

## Submission Requirements

Submit to eCampus:

1. **Web app URL** from Task 1
2. **Screenshot** from Task 2 showing your mobile device with the added feature
